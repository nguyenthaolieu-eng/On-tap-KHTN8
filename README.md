# Website ôn tập KHTN lớp 8 – bản mở rộng

## Nội dung
- Giao diện phù hợp máy tính và điện thoại.
- Phần ôn lý thuyết khái quát Vật lí, Hóa học, Sinh học.
- 23 chủ đề luyện tập, ngân hàng câu hỏi trắc nghiệm kèm đáp án và giải thích.
- Thi thử tổng hợp 20 câu trong 20 phút.
- Chấm điểm tự động và theo dõi tiến độ trên trình duyệt.

## Lưu ý
Đây là ngân hàng câu hỏi mở rộng để làm nền tảng ôn tập, chưa được thẩm định chính thức và không thể cam kết thay thế toàn bộ SGK. Giáo viên cần đối chiếu từng bài, yêu cầu cần đạt và phân phối chương trình của trường trước khi sử dụng trong kiểm tra chính thức. Tiến độ lưu trên từng trình duyệt/thiết bị, không tự đồng bộ về giáo viên.

## Cập nhật website GitHub Pages hiện có
1. Giải nén tệp ZIP.
2. Mở repository GitHub đang dùng cho website.
3. Chọn **Add file → Upload files**.
4. Tải lên `index.html`, `style.css`, `app.js`, `README.md` từ thư mục đã giải nén.
5. Nhấn **Commit changes** để cập nhật các tệp cùng tên.
6. Chờ GitHub Pages triển khai vài phút, rồi mở link cũ và nhấn Ctrl+F5 để làm mới.

## Chạy thử
Mở `index.html` bằng Chrome hoặc Edge.
